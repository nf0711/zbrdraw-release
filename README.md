# ZBRDraw【無料】Word・Excel・PowerPoint に貼れて、あとから何度でも直せる図ツール

Word・Excel・PowerPoint に「画像」として貼れて、**あとから何度でも編集し直せる**、無料の図の作成ツールです (Windows 11、商用利用可)。

図のデータは、貼った画像の中に入っています。別の文書にコピーしてももう一度直せます。ZBRDraw が入っていない PC では、ふつうの画像として表示されます。

## インストール

1. zip を、好きな場所に展開します。
2. `install-exe.cmd` をダブルクリックします (管理者権限は要りません)。exe が使えない PC では、`install-powershell.cmd` を使います。
3. Word・Excel・PowerPoint を開き直すと、使えます。

署名のないプログラムなので、Windows やセキュリティソフトが、警告を出すことがあります。そのときは、zip の中の `app\README.md` の「困ったとき」を見てください。セキュリティソフトに止められる場合の、除外設定の手順も書いてあります。

## 使い方・起動方法

- Word: 新規作成、編集はダブルクリック、または Ctrl+Shift+E
- Excel: 新規作成、編集は Ctrl+Shift+E
- PowerPoint: リボンの「ZBRDraw」タブから

編集画面で「✓ 完了して閉じる」を押すと、文書の図が置き換わります。

## できること

- 四角・楕円・線・曲線・手書き・画像・部品を組み合わせて図が描ける
- コネクタ: 図形を動かしても線がついてくる、付け替えもできる
- 寸法線 (mm): 図形の角に固定する、補助線つきの寸法線。縮尺と mm 表示、ルーラー
- 部品ライブラリ: よく使う図形を登録して使い回せる
- 矢じり: LAN コネクタや USB など。自分の図形も矢じりに登録できる
- 画像の背景を透明にする: スクリーンショットを貼って背景色をクリック
- Visio の図 (.vsdx) の読み込み: 図形と寸法線が取り込める
- AI で部品を作る: 指示文をコピーして、AI (Copilot・ChatGPT など) の答えを貼り付けると部品ができる
- JSON での保存、SVG・PNG の書き出し
- Office がなくても、ブラウザーだけで使える

## よくある質問

### PowerPoint や Word に貼った図を、あとから編集し直せますか？
はい。図のデータが画像の中に入っているので、貼ったあとから何度でも直せます。

### Visio の代わりになりますか？
.vsdx を読み込んで編集できます。フローチャートや配置図などの日常的な作図なら無料でまかなえます。

### 対応環境は？
Windows 11、Microsoft 365 / Office 2024、Microsoft Edge で動作を確認しています。
