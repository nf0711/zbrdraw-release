# ZBRDraw

Word・Excel・PowerPoint に貼れて、あとから何度でも編集し直せる、図の作成ツールです (Windows 11、無料)。

## ダウンロード

右側の **Releases** の、最新版から、`ZBRDraw-1.0.0.zip` をダウンロードしてください。

## インストール

1. zip を、好きな場所に展開します。
2. `install-exe.cmd` をダブルクリックします (管理者権限は、要りません)。
3. exe が使えない PC では、`install-powershell.cmd` を使います。
4. Word・Excel・PowerPoint を開き直すと、使えます。

署名のないプログラムなので、Windows やセキュリティソフトが、警告を出すことがあります。そのときは、zip の中の `app\README.md` の「困ったとき」を見てください。
